# ISDN_Project-Robotic_LEGO_Assembly
Final project for the ISDN Robotic Fabrication with Python Course

## Supervisor's full-mark requirements (100 points)

The following requirements are the project's primary priorities and completion criteria:

1. **Accept the target structure directly as input.** Converting an image into a target structure is not required.
2. **Automatically generate the assembly sequence and determine where temporary support is needed.**
3. **Use both robotic arms to autonomously assemble two different structures.** Each structure must contain at least eight LEGO bricks and include at least one section requiring temporary support.

Fulfilling these requirements is sufficient for the supervisor's 100-point scope. Prioritize work that achieves and demonstrates these outcomes. Completing the entire master plan is not necessary once these requirements are fulfilled; additional master-plan features are secondary.
